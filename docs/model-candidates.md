# 로컬 모델 후보 및 벤치마크 계획 (PRD-02)

## 원칙

- 후보 모델은 S22에서 성능·메모리·품질을 실측한 후 확정한다. (PRD-00: 문서만 보고 최종 모델을 고정하지 않는다)
- 개발용 클라우드 모델은 최종 앱의 필수 의존성이 아니다.
- 현재 `EchoModel`은 개발용 임시 구현이며 `ChatModel` 인터페이스를 그대로 만족한다.

## 교체 지점

```kotlin
// OnDeviceAiApplication.kt (ServiceLocator)
val chatModel: ChatModel = EchoModel()   // → 로컬 LLM 구현체로 교체
```

UI·엔진 코드 변경 없이 구현체만 교체하면 된다.

## 후보 런타임

| 런타임 | 특징 | 비고 |
|---|---|---|
| MediaPipe LLM Inference | Google 공식, GGUF 지원, Android 네이티브 | 1차 후보 |
| llama.cpp (JNI) | 광범위한 모델 지원, 양자화 | 빌드 복잡도 높음 |
| MLC LLM | GPU 가속(Vulkan), 컴파일 기반 | 모델별 사전 컴파일 필요 |

## 후보 모델 (경량 양자화, 추정치 — 실측 후 확정)

| 모델 | 파라미터 | 양자화 | 예상 메모리 | 상태 |
|---|---|---|---|---|
| Gemma 2 2B / Gemma 3n | 2~3B | Q4 | ~2GB | 후보 |
| Qwen2.5 1.5B | 1.5B | Q4 | ~1.2GB | 후보 |
| Phi-3.5 mini | 3.8B | Q4 | ~2.5GB | 후보 |
| Llama 3.2 1B | 1B | Q4 | ~0.8GB | 후보 |

한국어 품질을 고려해 Qwen2.5 계열과 Gemma 계열을 우선 실측한다.

## 벤치마크 항목 (S22 실측)

1. 토큰/초 (생성 속도)
2. 첫 토큰까지 지연 (TTFT)
3. 메모리 사용량 (peak RSS)
4. 로딩 시간
5. 배터리/발열 (장시간 대화)
