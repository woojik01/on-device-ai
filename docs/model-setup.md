# 로컬 모델 배치 가이드 (S22 실기 테스트용)

모델 바이너리(수백 MB~수 GB)는 Git에 커밋하지 않는다. **앱 내 자동 다운로드**가 기본 경로다.

## 1. 앱에서 자동 다운로드 (권장)

1. 앱 → **설정 → 로컬 모델 → "모델 자동 다운로드"**
2. 진행률 표시와 함께 다운로드 (약 1.3GB, 와이파이 권장)
3. 완료되면 표시가 `사용 중: mediapipe-...`로 바뀐다

기본 다운로드 대상 (게이트 없는 공개 Hugging Face 저장소):
- **Gemma 2B IT CPU int4** (`gemma-2b-it-cpu-int4.bin`, 약 1.3GB) — ASahu16/gemma

## 2. 파일에서 가져오기 (대안)

기기에 이미 모델 파일이 있다면: "파일에서 가져오기" → `.task`/`.bin`/`.gguf` 선택

가져오기/다운로드 실패 시 안내:
- "네트워크 확인" → 다운로드 중 연결 끊김
- "저장 공간" → 모델 크기의 2배 이상 여유 필요

## 3. 동작 확인

- 모델 파일이 있으면: `MediaPipeModel`로 로컬 추론 (오프라인 동작)
- 없으면: 개발용 `EchoModel` 폴백 — 설정 화면에 "로컬 모델 없음" 표시

## 4. 데이터 원칙

모델 파일 다운로드만 외부 네트워크를 사용한다. **대화·기억·상태는 절대 서버로 전송되지 않는다.**
