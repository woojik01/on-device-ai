# PRD-01 Android 앱 기반

## 목표

실제 Samsung Galaxy S22에 설치하고 실행할 수 있는 앱의 기반을 만든다.

## 기능

- 앱 실행
- 메인 채팅 화면
- 설정 화면
- 캐릭터 표시 영역
- 대화 목록
- 텍스트 입력창
- 전송 버튼
- 기본 앱 상태 저장
- 다크/라이트 테마
- Android 생명주기 대응

AI 응답은 아직 구현하지 않는다.

## UI 원칙

채팅 화면은 이후 AI 기능을 추가해도 레이아웃이 크게 변경되지 않도록 구성한다.

최소 구조:

`캐릭터 영역 / 메시지 목록 / 입력 영역 / 설정 진입점`

## 기술 요구사항

- Kotlin
- Jetpack Compose
- ViewModel 기반 상태 관리
- UI와 비즈니스 로직 분리
- 기능별 패키지 분리
- 문자열/치수/테마 값 중앙 관리
- 로컬 저장 계층 추상화

## 개발·테스트 환경

- GitHub 저장소에서 모든 변경사항 관리
- 클라우드 개발 환경에서 Gradle 빌드 가능
- 단위 테스트와 Compose 테스트를 추가
- 생성된 APK를 실제 S22에 설치하여 확인

## 테스트

1. 앱 설치
2. 앱 실행
3. 화면 이동
4. 메시지 입력
5. 전송 버튼 동작
6. 백그라운드 전환/복귀
7. 강제 종료 후 재실행
8. 화면 크기 및 다크 모드 확인

## 완료 조건

S22에서 크래시 없이 기본 화면을 사용할 수 있고, 자동 빌드/테스트가 통과하며 이후 AI 기능을 연결할 수 있는 구조가 확보된다.
