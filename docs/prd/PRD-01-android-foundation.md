# PRD-01 Android 앱 기반

## 목표

실제 Android 기기에 설치할 수 있는 최소 앱을 만든다.

## 기능

- 앱 실행
- 메인 화면
- 채팅 화면 골격
- 설정 화면 골격
- 앱 상태의 기본 저장 구조
- 다크/라이트 테마 대응
- 화면 회전 및 일반적인 Android 생명주기 대응

## UI

메인 채팅 화면에는 최소한 다음이 존재한다.

- 캐릭터 영역
- 대화 목록
- 텍스트 입력창
- 전송 버튼
- 설정 진입점

아직 AI 응답은 구현하지 않는다.

## 기술 요구사항

- Kotlin
- Jetpack Compose
- 단일 앱 모듈로 시작해도 되지만 패키지는 기능별로 분리
- 문자열/색상/치수 등 반복 값은 중앙 관리
- UI와 비즈니스 로직을 직접 결합하지 않는다.

## 테스트

1. 실제 S22 설치
2. 앱 실행
3. 화면 이동
4. 입력창 사용
5. 앱 백그라운드 전환 후 복귀
6. 앱 강제 종료 후 재실행

## 완료 조건

실제 S22에서 크래시 없이 기본 화면을 사용할 수 있고, 이후 AI 기능을 붙일 수 있는 구조가 확보된다.
