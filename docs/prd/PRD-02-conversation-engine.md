# PRD-02 대화 엔진

## 목표

AI와 텍스트로 대화할 수 있는 최소 제품을 만든다.

## 핵심 구조

사용자 입력
→ 대화 컨텍스트 구성
→ LLM 추론
→ 스트리밍 또는 단계적 응답
→ 화면 출력

## 요구사항

- 사용자 메시지 표시
- AI 메시지 표시
- 대화 중복 전송 방지
- 생성 중 상태 표시
- 생성 취소
- 오류 표시
- 빈 입력 차단
- 대화 기록 유지

## 모델 추상화

앱은 특정 LLM에 직접 종속되지 않는다.

예시 인터페이스:

`ChatModel.generate(context)`

향후 다음을 교체할 수 있어야 한다.

- 로컬 모델
- 더 작은 모델
- 다른 로컬 런타임
- 개발용 클라우드 모델

## 온디바이스 1차 목표

S22에서 실행 가능한 경량 양자화 모델을 우선 사용한다. 모델은 실제 벤치마크 후 확정한다.

## 프롬프트

시스템 프롬프트, 대화 기록, 캐릭터 정보, 기억 정보가 서로 분리되어 조립되도록 한다.

## 테스트

- 정상 질문
- 긴 질문
- 빈 질문
- 빠른 연속 전송
- 생성 취소
- 모델 오류
- 앱 재실행

## 완료 조건

실제 S22에서 로컬 모델을 이용해 텍스트 대화를 수행할 수 있고, 모델 교체를 위해 UI 코드를 수정할 필요가 없다.
