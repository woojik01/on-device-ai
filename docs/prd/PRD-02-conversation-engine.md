# PRD-02 대화 엔진

## 목표

로컬 LLM을 사용하여 실제 텍스트 대화를 구현한다.

## 핵심 흐름

사용자 입력
→ 컨텍스트 구성
→ 로컬 LLM 추론
→ 스트리밍 응답
→ 화면 표시

## 요구사항

- 사용자 메시지 표시
- AI 메시지 표시
- 생성 중 상태 표시
- 생성 취소
- 빈 입력 차단
- 연속 입력/중복 전송 방지
- 모델 오류 표시
- 대화 기록 유지
- 긴 응답 처리
- 앱 재실행 후 대화 기록 복원

## 모델 추상화

UI는 특정 모델에 직접 의존하지 않는다.

예시 개념:

`ChatModel.generate(request): Flow<Token>`

교체 가능 대상:

- 로컬 LLM
- 더 작은 양자화 모델
- 다른 로컬 런타임
- 개발용 클라우드 모델

개발용 클라우드 모델은 최종 앱의 필수 의존성이 아니다.

## 온디바이스 모델

S22에서 실제 측정 가능한 경량 양자화 모델을 후보로 검증한다.

후보 모델은 성능·메모리·품질을 측정한 후 확정하며, 문서만 보고 최종 모델을 고정하지 않는다.

## 컨텍스트

컨텍스트 조립을 다음 요소로 분리한다.

- 시스템 지침
- 캐릭터 정보
- 현재 상태
- 관련 기억
- 최근 대화
- 현재 사용자 입력

## 오류 처리

- 모델 로딩 실패
- 메모리 부족
- 생성 실패
- 생성 취소
- 모델 파일 누락

각 상황에서 앱이 종료되지 않고 사용자에게 복구 가능한 메시지를 보여준다.

## 테스트

- 정상 질문
- 빈 입력
- 긴 입력
- 빠른 연속 전송
- 생성 취소
- 모델 오류
- 앱 재실행
- 오프라인 상태

## 완료 조건

S22에서 인터넷 없이 로컬 모델을 이용해 텍스트 대화가 가능하고, UI 코드를 변경하지 않고 모델 구현을 교체할 수 있다.
