# PRD-07 온디바이스 최적화 및 출시

## 목표

개발용 프로토타입을 실제 사용할 수 있는 온디바이스 AI 앱 v1.0으로 만든다.

## 모델 확정

S22에서 후보 모델을 직접 측정한다.

측정 항목:

- 모델 로딩 시간
- 첫 토큰까지 시간
- 초당 생성 토큰
- RAM 사용량
- 장시간 사용 시 발열
- 배터리 소모
- 응답 품질

측정 결과를 기준으로 v1.0 기본 모델을 확정한다.

## 최적화

- 컨텍스트 길이 제한
- 최근 대화 압축
- 장기 기억 검색량 제한
- 불필요한 DB 조회 제거
- 모델 로딩/해제 최적화
- UI 스레드와 추론 작업 분리
- 스트리밍 응답
- 앱 재실행 시 상태 복구

## 오프라인 검증

비행기 모드 또는 네트워크 차단 상태에서:

- 앱 실행
- 대화
- 기억 생성
- 기억 검색
- 감정/관계 상태 변경
- 음성 기능의 가능한 범위
- 앱 재실행

을 검증한다.

AI 핵심 기능이 인터넷 없이 동작해야 한다.

## 데이터 관리

- 기억 전체 삭제
- 대화 기록 삭제
- 앱 데이터 초기화
- 필요한 경우 데이터 백업/복원

## 출시 기준

- 실제 S22에서 반복 사용 가능
- 치명적 크래시 없음
- 오프라인 핵심 대화 가능
- 기억 유지
- 감정/관계 유지
- 음성 기능 정상
- 모델 및 데이터가 앱 종료 후 정상 복구
- 개인정보를 외부 서버에 전송하지 않음

## 최종 산출물

- 설치 가능한 Android APK/AAB
- 소스 코드
- 모델 설치/배치 방법
- 사용자 설명서
- 성능 벤치마크 결과
- 알려진 제한사항
