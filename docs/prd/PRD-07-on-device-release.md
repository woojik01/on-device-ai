# PRD-07 온디바이스 최적화 및 출시

## 목표

프로토타입을 실제 사용할 수 있는 온디바이스 AI 앱 v1.0으로 마무리한다.

## 모델 벤치마크

S22에서 후보 모델을 동일 조건으로 측정한다.

측정 항목:

- 모델 파일 크기
- 로딩 시간
- 첫 토큰까지 시간
- 생성 속도(tokens/s)
- RAM 사용량
- 장시간 사용 시 발열
- 배터리 소모
- 응답 품질
- 앱 안정성

측정 결과와 사용성을 기준으로 v1.0 기본 모델을 결정한다.

## 최적화

- 컨텍스트 길이 제한
- 최근 대화 압축
- 기억 검색량 제한
- DB 조회 최적화
- 모델 로딩/해제 최적화
- 추론 작업과 UI 스레드 분리
- 스트리밍 출력
- 앱 재실행 상태 복구
- 메모리 부족 상황 처리

## 오프라인 검증

네트워크를 차단한 상태에서 다음을 모두 확인한다.

- 앱 실행
- 모델 로딩
- 텍스트 대화
- 기억 생성
- 기억 검색
- 감정/관계 변경
- 앱 재실행
- 핵심 데이터 복구

음성 기능은 실제 기기의 오프라인 STT/TTS 지원 범위를 별도로 기록한다.

## 데이터 관리

- 대화 전체 삭제
- 기억 전체 삭제
- 앱 데이터 초기화
- 필요한 경우 로컬 데이터 백업/복원

## 출시 검증

- 반복 실행 중 치명적 크래시 없음
- 오프라인 핵심 대화 가능
- 기억 유지
- 감정/관계 유지
- 모델 파일 손상/누락 처리
- 개인정보의 불필요한 외부 전송 없음
- APK 설치 및 업데이트 가능
- 실제 S22에서 최종 회귀 테스트 통과

## 문서

최종 저장소에 다음을 포함한다.

- 설치 방법
- 모델 설치/배치 방법
- 지원 Android 버전
- 기준 기기
- 성능 벤치마크
- 테스트 결과
- 알려진 제한사항

## 최종 산출물

- 설치 가능한 APK
- 필요 시 배포용 AAB
- 전체 소스 코드
- PRD 및 개발 문서
- 성능 측정 결과
- 알려진 제한사항

## 완료 조건

S22에서 인터넷 없이 핵심 AI 대화가 가능하고, 캐릭터·기억·감정·관계 상태가 지속되며, 반복 사용 가능한 수준의 안정성을 확보한다.
