# PRD-00 프로젝트 기준

## 1. 목적

온디바이스 AI 여자친구 Android 앱의 전체 범위와 단계별 개발 규칙을 고정한다.

## 2. 제품 정의

휴대폰에서 개인용 AI 캐릭터와 대화하는 Android 앱이다. 핵심 AI 추론, 대화 기록, 장기 기억, 캐릭터 상태는 가능한 한 기기 내부에서 처리·저장한다.

## 3. 핵심 사용자 경험

사용자는 앱을 열고 바로 캐릭터와 대화한다.

`사용자 입력 → 관련 기억/상태 검색 → 로컬 LLM → 응답 → 기억/상태 갱신`

앱을 종료했다가 다시 실행해도 캐릭터가 이전 상태와 중요한 기억을 유지해야 한다.

## 4. 기준 기기

- 1차 기준 기기: Samsung Galaxy S22
- Android 버전은 실제 테스트 기기에서 확인하여 빌드 시점에 기록한다.
- 성능이 부족한 경우 기능을 삭제하기보다 더 작은 양자화 모델 또는 다른 로컬 런타임을 선택한다.

## 5. 개발 방식

사용자가 직접 코딩하지 않는 것을 전제로 한다.

- 소스 저장소: GitHub `woojik01/on-device-ai`
- AI 개발 에이전트가 코드 작성·수정·테스트 보조를 담당한다.
- 휴대폰에서 GitHub 작업을 확인하고 지시할 수 있어야 한다.
- 클라우드 개발 환경에서 빌드·자동 테스트를 수행한다.
- 최종 기능은 실제 S22에 설치하여 검증한다.
- 각 PRD는 독립적인 완료 기준을 가진다.

## 6. 기술 방향

- Kotlin
- Jetpack Compose
- 로컬 DB: SQLite 계열
- 로컬 LLM 런타임: 실제 기기 벤치마크 후 확정
- 모델은 앱 코드와 분리하여 교체 가능하게 설계
- 개발용 클라우드 AI와 최종 사용자용 로컬 LLM을 분리

## 7. 데이터 원칙

기본적으로 다음을 서버에 보내지 않는다.

- 대화 내용
- 장기 기억
- 캐릭터 상태
- 관계 상태

개발 과정의 GitHub에는 개인정보나 실제 대화 데이터를 커밋하지 않는다.

## 8. v1.0 제외

- 다중 사용자
- 계정/서버 DB
- 인터넷 검색
- 클라우드 대화 의존
- 생성형 이미지
- 3D 아바타
- 복잡한 게임화
- 불필요한 소셜 기능

## 9. 단계 완료 규칙

각 단계는 다음을 만족해야 완료한다.

1. 요구 기능 구현
2. 기존 기능 회귀 테스트
3. 자동 빌드/테스트 통과
4. 실제 S22에서 핵심 시나리오 확인
5. PRD의 완료 조건 충족
6. 변경사항을 GitHub에 기록
