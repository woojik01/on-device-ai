# PRD-00 프로젝트 기준

## 1. 목적

프로젝트의 범위, 기술적 제약, 완료 판정 방식을 고정한다.

## 2. 제품 정의

제품은 Android 스마트폰에서 사용하는 개인용 AI 캐릭터 앱이다. 사용자는 캐릭터와 텍스트로 대화하고, 앱은 대화 맥락·기억·감정·관계 상태를 유지한다.

## 3. 핵심 원칙

- Android 스마트폰을 1차 실행 환경으로 한다.
- 개발 중에는 클라우드 AI를 사용할 수 있지만 최종 제품의 핵심 대화 추론은 온디바이스를 목표로 한다.
- 사용자 데이터는 기본적으로 로컬 저장한다.
- 서버 계정과 서버 DB는 v1.0 범위에서 제외한다.
- LLM 자체와 캐릭터 상태 관리 로직을 분리한다.
- UI, 저장소, AI 엔진을 모듈화하여 모델 교체가 가능해야 한다.

## 4. 1차 기준 기기

개발 및 성능 검증의 기준 기기는 사용자가 제공한 Samsung Galaxy S22로 한다.

단, S22에서 특정 모델의 성능이 부족하면 더 작은 양자화 모델로 대체할 수 있도록 설계한다.

## 5. 기술 방향

- Android
- Kotlin
- Jetpack Compose
- SQLite 계열 로컬 DB
- 로컬 LLM 런타임은 구현 단계에서 확정
- GGUF 등 교체 가능한 로컬 모델 형식 우선 검토

## 6. 범위 제외

v1.0에서는 다음을 만들지 않는다.

- 다중 사용자
- 서버 계정
- 클라우드 기반 장기 기억
- SNS
- 인터넷 검색
- 생성형 이미지 기능
- 3D 아바타
- 복잡한 게임화 시스템

## 7. 완료 조건

- 저장소 구조와 PRD가 존재한다.
- 개발 기준 기기와 핵심 제약이 문서화되어 있다.
- 이후 PRD에서 기술 선택을 변경할 수 있는 부분과 고정해야 하는 부분이 구분되어 있다.
