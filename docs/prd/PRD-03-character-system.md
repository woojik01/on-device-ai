# PRD-03 캐릭터 시스템

## 목표

LLM의 프롬프트 한 줄에 의존하지 않고 캐릭터의 정체성·말투·행동 특성을 구조적으로 관리한다.

## 캐릭터 데이터

- 이름
- 성격 특성
- 말투
- 좋아하는 것
- 싫어하는 것
- 가치관
- 습관
- 대화 금지 규칙
- 기본 관계 상태
- 캐릭터 콘텐츠 버전

## 응답 컨텍스트

`캐릭터 프로필 → 현재 상태 → 관련 기억 → 최근 대화 → 사용자 입력`

순서로 구조화된 컨텍스트를 생성한다.

## 불변성

일반 대화만으로 다음 정보가 임의로 변경되지 않는다.

- 이름
- 기본 성격
- 말투 규칙
- 핵심 가치관

사용자가 변경할 수 있는 항목은 별도 설정 기능에서 명시적으로 변경한다.

## 기본 캐릭터

v1.0에서는 최소 1명의 기본 캐릭터를 제공한다.

캐릭터 이름·이미지·세부 설정은 엔진 코드와 분리된 데이터로 관리한다.

## UI

설정에서 최소한 다음을 확인할 수 있다.

- 캐릭터 이름
- 현재 관계 단계
- 현재 기분
- 현재 친밀도

내부 프롬프트 원문을 기본 UI에 노출할 필요는 없다.

## 테스트

- 동일 캐릭터의 장기 대화에서 말투 유지
- 캐릭터 데이터 변경 반영
- 일반 대화로 핵심 설정이 임의 변경되지 않음
- 앱 재실행 후 캐릭터 설정 유지

## 완료 조건

코드를 수정하지 않고 캐릭터 데이터를 변경할 수 있고, 장시간 대화에서도 핵심 성격과 말투가 유지된다.
