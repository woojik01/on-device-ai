# PRD-03 캐릭터 시스템

## 목표

LLM에게 단순히 '여자친구처럼 행동하라'고 지시하는 대신 앱이 캐릭터의 정체성과 말투를 구조적으로 관리한다.

## 캐릭터 데이터

- 이름
- 기본 성격
- 말투
- 좋아하는 것
- 싫어하는 것
- 가치관
- 습관
- 금지된 행동
- 관계 상태

## 응답 생성

LLM에 전달되는 캐릭터 컨텍스트는 구조화된 데이터에서 생성한다.

예:

캐릭터 프로필
→ 현재 상태
→ 관련 기억
→ 최근 대화
→ 사용자 입력
→ 응답 생성

## 일관성

캐릭터 설정은 일반 대화의 영향을 받아 임의로 변경되지 않는다.

사용자에게 캐릭터 설정 변경을 허용하는 기능은 명시적인 설정 기능으로만 제공한다.

## v1.0 기본 캐릭터

개발 편의를 위해 최소 1명의 기본 캐릭터를 제공한다.

캐릭터의 이름·외형·세부 성격은 별도 콘텐츠 결정 사항으로 두며 엔진과 분리한다.

## 완료 조건

동일한 입력을 반복해도 기본적인 말투와 성격이 유지되고, 캐릭터 데이터 변경이 코드 수정 없이 가능한 구조를 갖춘다.
