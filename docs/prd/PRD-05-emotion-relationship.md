# PRD-05 감정·관계 시스템

## 목표

캐릭터의 상태가 대화와 행동에 따라 변화하고 이후 대화에 반영되도록 한다.

## 상태

v1.0 최소 상태:

- 기분
- 에너지
- 애정도
- 관계 단계

모든 수치는 명시적인 범위와 변화 규칙을 가진다.

## 상태 변경

앱의 상태 엔진이 변경량을 계산한다.

예:

- 긍정적 상호작용 → 기분/애정도 증가
- 부정적 상호작용 → 기분 감소
- 장시간 대화 → 에너지 감소

정확한 수치와 이벤트는 플레이테스트를 통해 조정한다.

## LLM 권한

LLM은 상태를 직접 확정하지 않는다.

`사용자 입력 → 상태 이벤트 분석 → 상태 엔진 계산 → 저장 → 새 상태를 LLM에 제공`

으로 처리한다.

## 관계 단계

초기 구조는 수치 기반으로 한다.

예:

`낯선 사이 → 친한 사이 → 가까운 사이 → 특별한 관계`

실제 명칭과 임계값은 콘텐츠 확정 시 결정한다.

## 지속성

- 앱 종료 후 상태 유지
- 앱 재실행 후 상태 복구
- 기억과 상태를 혼동하지 않도록 별도 저장

## 테스트

- 긍정/부정 상호작용
- 장시간 대화
- 관계 단계 경계값
- 앱 재실행
- 상태가 LLM 응답에 반영되는지 확인
- LLM 출력만으로 상태가 비정상적으로 변경되지 않는지 확인

## 완료 조건

대화에 따라 상태가 규칙대로 변화하고, 그 상태가 이후 응답에 영향을 주며, 재실행 후에도 유지된다.
