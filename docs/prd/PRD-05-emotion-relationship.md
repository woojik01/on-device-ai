# PRD-05 감정·관계 시스템

## 목표

캐릭터가 대화마다 상태가 달라지고 그 상태가 이후 대화에 반영되도록 한다.

## 상태

최소 상태:

- 기분
- 에너지
- 애정도
- 관계 단계

상태 값의 범위와 변화량은 코드에서 명확하게 정의한다.

## 변화

사용자의 행동과 대화에 따라 상태가 조금씩 변한다.

예시:

- 긍정적 상호작용 → 기분/애정도 증가
- 부정적 상호작용 → 기분 감소
- 장시간 대화 → 에너지 감소

단, LLM이 임의로 수치를 직접 변경하지 못하도록 한다.

## 관계 단계

관계 단계는 수치 기반으로 관리한다.

예:

`낯선 사이 → 친한 사이 → 가까운 사이 → 특별한 관계`

실제 단계 이름과 임계값은 콘텐츠 결정 단계에서 확정한다.

## LLM 역할

앱이 계산한 현재 상태를 LLM에 전달한다.

LLM은 상태를 표현할 수 있지만 상태 데이터 자체를 임의로 확정하지 않는다.

## 완료 조건

대화에 따라 상태가 변하고, 상태가 다음 대화의 말투와 내용에 영향을 주며, 앱 재실행 후 상태가 유지된다.
