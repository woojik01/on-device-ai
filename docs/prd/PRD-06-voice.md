# PRD-06 음성 시스템

## 목표

텍스트 기반 대화 엔진을 변경하지 않고 음성 입출력을 추가한다.

## 입력

마이크
→ Android 음성 인식
→ 텍스트
→ 기존 대화 엔진

## 출력

LLM 텍스트
→ Android TTS
→ 스피커

## 요구사항

- 음성 입력 시작
- 음성 입력 종료
- 인식 중 상태 표시
- 인식 실패 처리
- AI 응답 자동 읽기 옵션
- 읽기 중지
- 텍스트/음성 대화의 동일한 기억 공유
- 텍스트/음성 대화의 동일한 감정·관계 상태 공유

## 오프라인 원칙

음성 인식/TTS가 기기에서 제공하는 오프라인 기능을 우선 사용한다.

기기 또는 Android 버전에서 오프라인 음성 기능을 사용할 수 없는 경우 이를 명확하게 표시하며, 핵심 텍스트 대화는 계속 사용할 수 있어야 한다.

## 권한

마이크 권한을 필요한 시점에 요청한다.

거부 시 텍스트 대화는 정상적으로 사용할 수 있어야 한다.

## 테스트

- 음성 입력
- 짧은 문장
- 긴 문장
- 인식 실패
- 권한 거부
- TTS 재생
- TTS 중지
- 음성 후 기억 생성
- 음성 후 관계/감정 상태 반영

## 완료 조건

S22에서 음성으로 질문하고 AI 답변을 들을 수 있으며, 텍스트 대화와 동일한 기억·상태 시스템을 사용한다.
