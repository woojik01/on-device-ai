# PRD-06 음성 시스템

## 목표

텍스트 기반 AI를 음성으로 사용할 수 있게 한다.

## 입력

마이크
→ Android 음성 인식
→ 텍스트
→ 대화 엔진

## 출력

LLM 텍스트
→ Android TTS
→ 음성 재생

## 요구사항

- 음성 입력 시작/종료
- 인식 중 상태 표시
- 인식 실패 처리
- AI 응답 읽기
- 읽기 중 중지
- 텍스트 대화와 음성 대화의 동일한 기억/상태 사용

## 원칙

음성 시스템은 LLM과 분리한다.

음성 기능 때문에 대화 엔진이나 기억 시스템의 구조를 변경하지 않는다.

## 완료 조건

실제 S22에서 음성으로 질문하고 AI의 답변을 음성으로 들을 수 있으며, 텍스트 대화와 동일한 기억 및 관계 상태를 공유한다.
