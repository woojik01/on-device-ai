# PRD-04 기억 시스템

## 목표

이전 대화에서 중요한 정보를 로컬에 저장하고 관련 대화에서 다시 활용한다.

## 기억 종류

### 단기 기억

최근 대화의 원문 또는 압축된 대화 맥락.

### 장기 기억

장기간 유용한 정보만 저장한다.

예:

- 사용자가 좋아하는 것
- 사용자가 싫어하는 것
- 반복적으로 언급한 정보
- 중요한 사건
- 사용자가 명시적으로 기억해 달라고 한 내용

## 데이터

최소 필드:

- id
- 내용
- 유형
- 중요도
- 생성 시각
- 마지막 사용 시각
- 출처 대화 식별자
- 활성 여부

## 기억 생성

모든 메시지를 무조건 장기 기억으로 저장하지 않는다.

기억 후보를 추출한 뒤 중요도/중복 여부를 확인하고 저장한다.

## 검색

1차 구현은 로컬 텍스트/키워드 검색으로 시작한다.

성능과 품질이 필요한 경우 로컬 임베딩 검색을 추가할 수 있다.

매 대화마다 전체 기억을 LLM에 전달하지 않는다.

## 사용자 제어

사용자는 다음을 할 수 있어야 한다.

- 저장된 기억 목록 확인
- 개별 기억 삭제
- 전체 기억 삭제

## 개인정보

기억은 기본적으로 로컬 DB에 저장한다.

실제 사용자 대화와 기억을 GitHub에 커밋하지 않는다.

## 테스트

- 중요 정보 기억
- 중요하지 않은 대화가 무분별하게 기억되지 않음
- 관련 기억 검색
- 무관한 기억 제외
- 앱 재실행 후 유지
- 개별 삭제
- 전체 삭제

## 완료 조건

앱을 종료해도 중요한 기억이 유지되고, 관련 대화에서 해당 기억이 자연스럽게 사용된다.
