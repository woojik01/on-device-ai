# PRD-04 기억 시스템

## 목표

AI가 이전 대화를 의미 있게 기억하도록 한다.

## 기억 종류

### 단기 기억

최근 대화 내용을 유지한다.

### 장기 기억

사용자 또는 관계에 장기적으로 유용한 정보만 별도로 저장한다.

예:

- 사용자가 좋아하는 것
- 사용자가 싫어하는 것
- 반복적으로 언급하는 정보
- 중요한 약속이나 사건
- 사용자가 명시적으로 기억해 달라고 한 내용

## 저장

기억은 로컬 DB에 저장한다.

최소 필드:

- id
- 내용
- 종류
- 중요도
- 생성 시각
- 마지막 사용 시각

## 검색

모든 장기 기억을 매번 LLM에 전달하지 않는다.

사용자 입력을 기준으로 관련성이 높은 기억을 선택하여 컨텍스트에 넣는다.

초기 구현에서는 단순 키워드/텍스트 검색으로 시작할 수 있다. 성능과 품질을 확인한 후 임베딩 검색을 추가한다.

## 사용자 제어

사용자는 저장된 기억을 확인하고 삭제할 수 있어야 한다.

## 개인정보

기억 데이터는 기본적으로 외부 서버로 전송하지 않는다.

## 테스트

- 대화 후 기억 생성
- 관련 없는 기억 제외
- 관련 기억 검색
- 앱 재실행 후 기억 유지
- 특정 기억 삭제
- 전체 기억 초기화

## 완료 조건

앱을 종료하고 다시 실행해도 중요한 사용자 정보가 유지되며, 관련 대화에서 해당 정보가 자연스럽게 반영된다.
